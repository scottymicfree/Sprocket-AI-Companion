# Microsoft Store publication plan

**App:** Sprocket — AI Desktop Companion  
**Studio:** Fenton Lab (publisher name subject to Microsoft account verification)  
**Commercial model:** Planned paid base companion; **price not set** and no offer currently available  
**Target:** Windows 10/11

## What's included

The intended base purchase will cover the companion program, core character behavior, a limited local-memory allowance, and free evolution improvements and character-motion updates under eventual product terms. Specific paid add-ons, expanded memory options, and prices are not yet determined. It **does not include unlimited third-party cloud inference**. Supported providers and any separate accounts/charges must be disclosed before purchase.

## Delivery

Compare a Store-supported Win32 installer with MSIX using actual prototype tests. MSIX improves installation/update management but **does not automatically sandbox a full-trust desktop app**.

Do not ship a provider master API key, customer database, personal documents, or private Lucy sources inside any package.

## Store release preparation

- Verify publisher account, reserve product identity, and choose commerce model.
- Resolve Sprocket/Rivet-derived sprite rights and all dependency notices.
- Produce a packaged, clean-machine-tested build with rollback/uninstall behavior.
- Supply privacy disclosures, support contact, AI safety/reporting control, screenshots, and accessibility checks.
- Confirm Store policies, pricing, certification, and release receipts.

**Current state: documentation and planning, not a published app.**
